## 화면 구성 (3개)

### 1) 리그/팀 대시보드 (`/`)
```
┌───────────────────────────────────────────────────────────────┐
│ KBO 부상 이탈 트래커   [시즌: 2021–2025 ▾] [구단: 전체 ▾]        │
├──────────────┬────────────────────────────────────────────────┤
│ 리그 요약     │  IAI 랭킹 (상위 20)                              │
│ 총 부상 N건   │  # 선수   구단  포지션  건수  결장일  9월↑  IAI      │
│ 총 결장 N일   │  1 ○○○   ○○   투수    7    164    2    12.4 ■■■■ │
│ 최다 부위:    │  2 ...                                         │
│  햄스트링     │                                                 │
├──────────────┴────────────────────────────────────────────────┤
│ 부위별 리그 히트맵 (신체 SVG 1개, 리그 합산)  │ 구단별 결장일 막대   │
└───────────────────────────────────────────────────────────────┘
```

### 2) 구단 페이지 (`/team/[id]`)
- 선수 카드 그리드. 카드마다 **작은 신체 SVG 썸네일** + IAI 숫자.
- 정렬: IAI / 결장일 / 포지션.

```

│ 근거 기사 목록 (날짜 · 언론사 · 제목 · 링크) · [검수: 확인/오탐]   │
└─────────────────────────────────────────────────────────────┘
```

## 신체 SVG 스펙
- 앞면/뒷면 2개 실루엣, viewBox `0 0 200 440`, 중립 회색 실루엣 위에 **zone path** 를 올린다.
- 각 zone은 `data-zone="hamstring_l"` 같은 id를 가지며 DB `body_parts.svg_zone` 과 1:1.
- 좌/우 구분이 기사에 없으면 양쪽 모두 동일 색으로 칠하되 투명도 낮춤.
- 색은 CSS 변수로만 지정:
  - `--inj-0: transparent`
  - `--inj-1 (노랑): #F5C842`
  - `--inj-2 (주황): #F0872B`
  - `--inj-3 (빨강): #D7263D`
  - 다크모드에서도 동일 색, 실루엣만 `#2A2E35` 로 변경.
- 색맹 대응: 색 외에 zone 위 숫자(건수) 라벨을 항상 표시.
